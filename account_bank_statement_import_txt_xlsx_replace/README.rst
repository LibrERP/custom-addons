Description
===========
This module allows you to import TXT/CSV or XLS/XLSX bank statements file in Odoo.

**Table of contents**

.. contents::
   :local:

Configuration
=============

To create TXT/CSV/XLSX statement sheet columns mapping:

#. Open *Invoicing > Configuration > Accounting > Statement Sheet Mappings*
#. Create mapping(s) according to your online banking software statement format

Timestamp Format should be in format "%d/%m/%Y"

Columns should be indicated like the name of the column: "Descrizione"

In case the title of the table is more that 1 line and the column title is not on the row preceding the first data row, it can be indicated with the letter, like this: "Descrizione:D"

Usage
=====

To use this module, you need to:

#. Get statement in TXT/CSV or XLSX from your online banking software
#. Go to Odoo and and import the statement file, selecting corresponding format
